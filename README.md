# Purriod

一款经期记录、预测和分析的微信小程序应用。

## 项目定位

Purriod（经期猫）面向 18-45 岁女性，提供简洁、温柔、低打扰的经期记录与周期预测体验。

## 第一版功能

- 经期首页：今日状态、下次经期预测、周期圆环、一键记录开始/结束
- 记录页面：月历视图、每日记录、流量/痛经/白带/心情/症状标签
- 我的页面：经期设置、隐私说明、清除我的数据、关于 Purriod
- 分析能力：平均周期、平均经期、最近六个周期与经期天数趋势图
- 离线保存：本地即时保存，联网后自动同步云数据库

## 技术栈

- 微信小程序原生框架
- TypeScript
- 微信云开发
- 原生 Canvas 2D
- Node.js 内置测试运行器

## 数据范围与隐私

- 只保存用户主动填写的周期设置、经期日期、流量、痛经、白带、心情、症状和备注。
- 本地保存用于断网可用，云数据库用于同一微信身份的数据同步。
- 云端删除成功后才清理本地健康数据；云端失败时保留本地数据并提示用户重试。
- 周期预测和趋势仅供日常记录参考，不构成医疗判断。

## 第一版不包含

- 微信订阅消息提醒
- 社区和文章内容
- VIP、电商和广告
- 健康评分、风险判断、诊断或治疗建议

## 注意

Purriod 仅用于经期记录、周期预测和个人统计分析，不提供医疗诊断、治疗建议或医疗服务。
