# Purriod

一款经期记录、预测和分析的微信小程序应用。

## 项目定位

Purriod（经期猫）面向 18-45 岁女性，提供简洁、温柔、低打扰的经期记录与周期预测体验。

## 第一版功能

- 经期首页：今日状态、下次经期预测、周期圆环、一键记录开始/结束
- 记录页面：月历视图、每日记录、流量/痛经/白带/心情/症状标签
- 我的页面：经期设置、隐私说明、清除我的数据、关于 Purriod
- 分析能力：平均周期、平均经期、经期次数等基础统计

## 技术栈

- 微信小程序原生框架
- TypeScript
- 微信云开发

## 云开发环境

当前配置的云开发环境 ID：

```text
cloud1-d3gth40uhfb98e9c6
```

建议在云开发控制台创建以下数据库集合：

- `user_settings`
- `period_records`

集合权限建议设置为“仅创建者可读写”，或使用安全规则限制用户只能读写自己的数据。

## 开发

使用微信开发者工具打开本项目即可开始开发。

## 注意

Purriod 仅用于经期记录、周期预测和个人统计分析，不提供医疗诊断、治疗建议或医疗服务。
